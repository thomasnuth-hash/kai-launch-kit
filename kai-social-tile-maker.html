LinkedIn carousel

A LinkedIn carousel is a PDF: each page is one slide, and LinkedIn shows them as a swipeable deck. Build it here page by page.

How to build a carousel
  1. Start with the source. On the Tile tab, drop the blog .docx into Source text (or paste it), then come back here and press Fill from the blog. You get a title slide, one stat slide per figure found, and a closing call-to-action slide. Skip this if you are writing slides by hand.
  2. Add or reorder pages. + Slide inserts a page after the selected one; Duplicate copies it; ← Move / Move → reorder. Click a number in the strip to select a page. Six to ten pages is the sweet spot on LinkedIn.
  3. Edit the selected page. Under This slide choose the Kind — Headline for a title or key point, Stat for a counting figure (fill Prefix / Figure / Suffix, e.g. “77” + “%”), Quote for a pull-quote, Closing call to action for the last page (it carries the button and link from the Tile tab). Pick a Category for its colours; write the Eyebrow, Headline and Emphasis. The preview on the right always shows the selected page.
  4. Bulk add. Type one slide per line in the box below: 77% | of CISOs report burnout makes a stat slide; a line without a figure makes a headline slide. Press Add these lines.
  5. Pick the page size. 1080×1350 (4:5) is the LinkedIn standard; square also works. All pages share one size.
  6. Download and post. Download carousel (PDF) renders every page. On LinkedIn, start a post, choose Add a document, upload the PDF, give it a title. Use Copy post text on the Tile tab for the caption and links.

Your deck is saved in this browser between sessions. Announcement categories (Partnership, Launch, Event, Web event) can be used as slides, but New hire and Speaker tiles are single-image posts and have no carousel.
